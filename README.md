# 美の基準 2. 格づけ — 構造化データ

真鶴町まちづくり条例「美の基準」デザインコードブックのうち、第2章「格づけ」（印刷ページ 28–49）を機械可読な形に起こしたもの。

## 中身

```
美の基準_02_格づけ.json   構造化データ本体
美の基準_02_格づけ.md     人が読む用（画像埋め込み）
images/                   切り出した写真・図 63点
```

キーワード10個（海の仕事 山の仕事／見通し／大きな門口／母屋／門・玄関／転換場所／建物の縁／壁の感触／柱の雰囲気／戸と窓の大きさ）。原典の見開き構成（左ページ＝キーワード・前提条件、右ページ＝解決法・課題）をそのままフィールドにしている。

## 原文と解釈の区別

原典に印刷されている文言：`前提条件` `解決法` `課題` `キャプション` `図中のラベル`

**転記者が判断して書いたもの：`解釈` `写っているもの` `注記`**

図には凡例がないため、何を示す図なのかは見た人が決めるしかない。そのため原文とは別フィールドに分けてある。空欄は未記述（十分な解像度で確認していないもの）。

## 画像について

元PDFは1ページ1枚のスキャン画像で、テキストレイヤーがない。ページを200dpiで展開し、インク密度による自動検出と目視確認で個別の図版を切り出した。

ファイル名は `{キーワードID}_photoNN.jpg` / `_figNN.jpg`。同一キャプションに複数の図版がある場合は末尾に a, b, c。章扉は `chapter_p28.jpg` `chapter_p29.jpg`。

既知の限界：

- 原典で隣接している図版は分離できていないものがある（該当箇所は `注記` に明記）
- p.33 左段の小写真2点は p.32 の写真の再掲のため未収録
- 「戸と窓の大きさ」の寸法図は 910×1,820 側のみ切り出せている

**キャプションと写真がずれている箇所がある。**「山の仕事、自然の中で、豊かな大地の実りを育てる」の写真はビニールハウスの中で、屋外の山林ではない。「山の仕事」が地形ではなく生業を指していると読める。
